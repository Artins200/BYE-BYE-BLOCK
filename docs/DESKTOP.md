# Настольная программа

Основной пользовательский режим BYE-BYE-BLOCK — обычное окно Windows, а не сайт.

## Возможности окна

- Кнопка **Старт / Стоп**.
- Выбор порта и DNS: DoH или системный.
- Опциональный внешний SOCKS5-туннель на `127.0.0.1`.
- Счётчики соединений, ошибок и трафика.
- Журнал работы.
- Копирование адреса прокси.
- Опциональное включение системного прокси Windows. Предыдущие значения сохраняются и возвращаются при остановке или закрытии окна.

Веб-панель осталась только как дополнительный инструмент для CLI/отладки. Для обычной работы она не нужна.

## Запуск

### Готовый `.exe`

Скачайте `BYE-BYE-BLOCK.exe` из Releases, запустите двойным кликом и нажмите **Старт**.

Python не требуется. Сборка PyInstaller может вызывать предупреждение SmartScreen, потому что файл не подписан коммерческим сертификатом. Проверяйте источник: релизы должны быть из этого репозитория.

### Из исходников

```bat
start.bat
```

Скрипт создаст `.venv`, установит зависимости и откроет окно программы.

Консольный режим:

```bat
start.bat --console --no-browser
```

## Сборка `.exe` вручную

```bat
start.bat --setup-only
build-windows.bat
```

Результат: `dist\BYE-BYE-BLOCK.exe`.

## Системный прокси

По умолчанию галочка системного прокси выключена. Если включить:

- программа запишет `127.0.0.1:<порт>` в пользовательские настройки прокси Windows;
- добавит исключения для localhost/локальных адресов;
- при остановке/выходе вернёт прежние значения.

Если программа была завершена аварийно, проверьте: Windows → Параметры → Сеть и Интернет → Прокси.

## Границы

Окно не делает блокировки «невидимыми» само по себе. Оно запускает тот же локальный прокси: HTTP CONNECT/SOCKS5, DoH, подбор стратегий. Для IP-блокировок и whitelist нужен доступный внешний туннель. UDP/QUIC и kernel-level desync пока не реализованы.

# Безопасность и границы

- Прокси слушает только loopback. Не открывайте его в LAN/интернет без отдельного аудита и аутентификации.
- По умолчанию запрещены non-public IP-цели и разрешены только типовые веб-порты. Это снижает риск SSRF из браузера.
- TLS certificate verification не отключается. Нет MITM, нет установки корневого сертификата.
- Dashboard read-only. В обычном режиме — loopback. `--demo` использует синтетические данные.
- Домены в событиях по умолчанию хешируются. Полные домены можно включить только осознанно (`log_domains = true`).
- Секреты upstream не должны попадать в git. Используйте `config.local.toml` и переменные окружения для автоматизации.
- Автоматический retry разрешён только для безопасных первых payload. Это не гарантия exactly-once для приложений.
- Фрагментация может ломаться на stateful DPI и некоторых серверах. Всегда сравнивайте с `direct`.
- Инструмент не предназначен для обхода аутентификации, санкционных geo-block сервисов, корпоративных политик доступа или для атак на инфраструктуру.
- Локальный desync не создаёт сетевой маршрут. При whitelist/отключении нужен доступный внешний канал или ничего.

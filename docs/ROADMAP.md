# Дорожная карта

## v0.2
- [ ] QUIC/HTTP-3 probe и явный TCP fallback профиль.
- [ ] Тест большого ответа (> 256 KB) для выявления throttling/обрыва после N байт.
- [ ] Импорт/экспорт профилей стратегий по доменам.
- [ ] Отдельные профили для Wi-Fi/mobile/ISP.
- [ ] Упаковка: PyInstaller/zipapp, systemd user unit, Windows startup script.

## v0.3
- [ ] Адаптер к внешним движкам (ByeDPI/zapret) как опциональный backend, с проверкой хешей релизов.
- [ ] SOCKS5 UDP ASSOCIATE или отдельный UDP relay, если появится безопасный сценарий.
- [ ] TLS fingerprint diagnostics без подмены личности клиента.
- [ ] Поддержка DoT/DoQ resolver.

## Исследовательское
- [ ] Набор контролируемых endpoint для DNS/SNI/IP/QUIC/throttling тестов.
- [ ] Повторяемые измерения по сетям и времени, без сбора чувствительных доменов пользователей.
- [ ] Сравнение стратегий на stateful DPI, а не только на «наивных» фильтрах.

## Не обещаем
- «100x лучше zapret» без бенчмарков.
- Обход любых блокировок без внешнего туннеля.
- Обход физического отключения сети.
- Незаметность от активного зондирования.
